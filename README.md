# Daedalus CRM

**下一代 CRM，跑在你自己的机器上。AI 起草，你来拍板。**

给小团队用的客户管理系统：线索、客户、跟进、商机、推荐归属。首页是一个 agent 对话面：问一位客户、问一个数，
它自己决定搜谁、读谁、查什么，每一步看得见；记录页粘一段聊天，AI 整理成记录，你点确认。工具全部只读，写永远由人点。
自己部署，数据在自己手里。默认按教培场景措辞，改个设置就能用于任何销售团队。

## 上手

**用 Docker**

```bash
git clone https://github.com/BeckY824/daedalus-crm.git && cd daedalus-crm
docker compose up -d
```

**或者本地跑**（Node 22+）

```bash
git clone https://github.com/BeckY824/daedalus-crm.git && cd daedalus-crm
npm install && npm run setup && npm run dev
```

然后打开 **http://localhost:3000**

| 用户名 | 密码 | 身份 |
|---|---|---|
| `admin` | `admin123` | 管理员 |
| `zhangsan` | `admin123` | 销售「张三」（演示） |
| `lisi` | `admin123` | 销售「李四」（演示） |

登录后到「设置管理 → 修改密码」把密码改掉。就这些。

**想用 AI**：管理员进「设置管理 → AI 接入」，填接口地址、API Key、模型名，点「测试连接」，保存。
DeepSeek、OpenAI、本地 Ollama、各种中转站都行。不填就没有 AI 入口，其余功能照常。

**不是教培**：「设置管理 → 业务配置」里把「学员」改成「客户」、「院校 / 年级 / 专业」改成你的字段名，全站同步。

## 有什么

| 客户列表 | 客户详情 |
|---|---|
| ![](docs/shots/04-customers.png) | ![](docs/shots/05-customer-detail.png) |

- **主链**：线索 → 客户 → 跟进 → 商机 → 签约，管道看板拖拽推进
- **推荐归属**：谁介绍的、业绩算谁的，录入时固化，改上游不追溯
- **不出错**：手机号查重、同金额签约二次确认、两人同时编辑按字段合并、全部写操作留痕
- **首页是一个对话面**，交互照 Claude Code / Codex：背后是一个 agent 循环，模型自己决定搜谁、读谁、查什么（工具全部只读），每次调用一行看得见，答完折成一句摘要；回答逐字流出，句末圆标能点回那条记录；答完给「打开 / 起草话术」动作。Enter 发送，正在答时再问会排队，Esc / Ctrl+C / 停止键打断；指标与图表在「数据看板」
- **记录页三栏**：左档案点一下就能改，中间一条时间线，顶部速记框粘一段微信聊天，AI 整理成跟进记录、待办、下次计划，你核对后保存，原文留存；右侧 AI 常驻，打开谁它已读完谁
- **AI 提议，你拍板**：让它「记一笔」「把他改成已签约」「约下周三」「新建一条线索」，它给一张建议卡，字段可以就地改，点确认才写进去，不确认什么都不会发生。它不知道的字段留空让你补，不会反过来要你照格式打一屏字；每次确认都记进操作日志
- **AI 只起草**：唤醒话术、转介绍邀请、盯盘解读都由 AI 写草稿，发消息永远由人在界面上点；接口地址 / Key / 模型在设置页填，DeepSeek、OpenAI、本地 Ollama 都行
- **模型随手换**：设置页配一张可选模型清单，首页输入框下面就能切，每个人各选各的
