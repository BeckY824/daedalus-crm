JS 那边的镜像在 `src/lib/palette.ts`。这份文档不是第二份出处——改数值改 :root，这里只解释为什么。

**能测的规矩都有守卫**（改坏了 CI 红，不靠人记）：

| 规矩 | 守卫 |
|---|---|
| 色值只许在 :root 和 palette.ts 里写死；两处一字不差；总数 ≤ 48 | `tests/design-tokens.test.ts` |

## 一、色

**语义色一套。** 每组「底 / 字 / 线」齐全，页面里只按语义取，不按"看起来像"取。

| 用途 | token | 值 |
|---|---|---|
| 主动作、焦点、链接。**一页只给一个主动作** | `--brand` | #2f6bff |
| 压在浅蓝上的字 | `--brand-deep` | #1a3f9e |
| 选中行、AI 的浅蓝材质 | `--brand-bg` / `--brand-line` | #eef2ff / #c7d6ee |
| 正文 | `--ink` | #111827 |
| 次一级正文：长段落、时间线 | `--ink-soft` | #374151 |
| 说明、元数据。**字色最浅到此为止** | `--text-muted` | #6b7280 |
| 只给 placeholder、禁用、装饰点。不许当正文 | `--text-faint` | #9ca3af |
| 压在深色底上的字 | `--on-ink` | #ffffff |
| 主分隔线 / 行间线 / 控件边框 | `--line` / `--line-soft` / `--line-strong` | #e5e7eb / #eceef2 / #d1d5db |
| 面板底 / 工作台底 / 悬停 / 整行悬停 | `--panel` / `--workbench` / `--hover` / `--row-hover` | #ffffff / #fafafa / #f0f1f4 / #f7f8fa |
| 成功 / 警告 / 危险，各带 -text -bg -line | `--success` `--warning` `--danger` | #16a34a / #d97706 / #dc2626 |

**分类色八个**（`--cat-blue` `green` `yellow` `orange` `pink` `violet` `cyan` `amber`）：
给"只是不同、没有高低"的东西——商机阶段、跟进类型、并列的图表线。**不表示好坏**，好坏用语义色。
图表主线用 `--brand`，不再有第二个蓝。

**头像底色八个**（`--avatar-1…8`）：按名字哈希选，字色一律 `--ink-soft`。

需要透明度：`palette.alpha(hex, 0.12)`，别手写 `#xxxxxx1f`。

## 二、字

五级，各带自己的字重，层级不靠字号一个人扛。**比 12px 小的字这套界面里不存在。**

| token | 值 | 用在 |
|---|---|---|
| `--fs-title` | 22 / 600 | 页面标题 |
| `--fs-section` | 15 / 600 | 区块标题 |
| `--fs-body` | 14 / 400 | 正文、表格 |
| `--fs-note` | 13 / 400 | 说明、元数据 |
| `--fs-min` | 12 / 500 | 下限 |
| `--fs-num` | 26 | 大数字（指标、金额），不属于五级 |
| `--ic` | 16 | 图标，不跟字号缩 |

行高 1.6。一段说明超过两行就该拆成列表。

## 三、间距与圆角

间距六档 `--s1…s6` = 4 / 8 / 12 / 16 / 24 / 32，**所有间距落在 4 的倍数上**。
圆角三档：控件 `--r-ctl` 6、卡片 `--r-card` 10、浮层 `--r-pop` 14。

## 四、动效

三条曲线、四档时长，**全站只有这些**（数值参考 bencho.dev，MIT）：

- `--ease` 绝大多数：出现、消失、位移
- `--ease-spring` 只给"弹出来"的：菜单、开关、确认态
- `--ease-morph` 一个东西变成另一个东西
- `--t-press` 90 / `--t-fast` 120 / `--t` 160 / `--t-slow` 180 / `--t-enter` 200 / `--t-morph` 320

按下那档故意最短：按下要立刻，松开才回弹。**减弱动态时不许有位移**——时长归零挡不住 transform。
JS 里的 motion 认不了 CSS 变量，只能抄数值：0.18s、`[0.2, 0.8, 0.2, 1]`。

## 五、骨架

左栏 `--rail-w` 220 永远在；中栏 `--pane-w` 312 **不是默认栏位**，只有需要名单的页才开；
顶部拖动区 `--drag-h` 52；表格行高 40、表头 36；主输入框下限 48。
导航稳定：任何页内动作都不该让左栏动、跳、换内容。

## 六、组件

基础组件 = antd（主题在 `lib/theme.ts`，值取自 palette）+ `components/ui.tsx`（StatCard、状态徽章、进度）。
新页面先用现成的；要造新组件，先问它和现有哪个是同一种东西。

## 七、原则（拍板过的）

- **少即是多**：只留必要的东西。一页一个主动作。
- **照形不照文字**：参考设计稿照的是形，文案按我们自己的口气写。
- 空态不写"暂无数据"，写这是什么、第一步该做什么。
- 说人话：过程条上写"查了渠道清单"，不写工具名。
