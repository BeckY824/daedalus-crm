# UI 体检 · 2026-09-19（第一轮）

对象：0.37.4 色板收敛之后的桌面端，12 个页面 × 有数据 / 空态 / 窄屏 1024 / 手机（`npx playwright test e2e/ui-walkthrough.spec.ts`，
截图在 `test-results/走查/`）。清单见 `docs/UI_REVIEW_CHECKLIST.md`。

**结论**：色板收敛没有改坏任何页面——新的邮件沟通粉、上门拜访紫、图表主蓝都对，表格 / 卡片 / 标签的灰度层级和以前一致。
真正的发现是设计层面的，四条，一条这一版改，三条记档。

| 页面 | 条目 | 结论 | 备注 |
|---|---|---|---|
| 客户详情 | 长文本 | **改了** | 侧栏「联系人」「商机」两行的名字截断成「母亲…」「方案报…」，但没有 title，鼠标停上去看不到全名 |
| 首页 / 数据·现在 | 颜色数量·少即是多 | 留着 → 0.38 | 右下三张小卡里两张（商机总金额、新增客户）和顶上的指标卡是同一个数，一屏出现两次。首页 0.38 要改版（全局 AI 面板 + 宽模式），到时一起收 |
| 客户 / 线索 / 跟进 | 颜色数量 | 留着 → 单独一版 | 状态标签用的是 antd 预设色名（`orange` `processing` `cyan` `success`…），是设计系统之外的第二套色板；「意向较高」和「已签约」两种绿。要动的是 `constants.ts` 里四张 *_STATUS_COLOR 表，8 处按值引用，单独做 |
| 首页 / 数据·本年 | 颜色数量 | 留着 | 四张指标卡右上角的图标各一个色（brand / 绿 / 琥珀 / 紫）。设计稿（08/DATA·NOW）如此，是装饰色不是分类色；先不动 |
| 商机管道 | 窗口 | 过 | 1280 宽下第五档在横向滚动区里，`.pipe` 是 `overflow-x: auto` 的看板，是看板该有的形，不算页面横向溢出 |
| 设置 · 团队成员 | 窗口 | 过 | 表格最右两列在卡片内横向滚动，antd 表格自己的行为 |
| 全部 | 对齐 / 留白 / 字号层级 / 状态完整性 / 动效 / 文案 | 过 | 空态都有引导（走查用例钉着）；字号五级；说明文字最浅到 `--text-muted`（visual-tokens 用例钉着） |

排除项：截图左下角的黑色 "N" 圆钮是 Next 16 的开发浮层，不是我们的 UI。

下一轮：0.38 首页改版落地后再跑一遍，重点看新面板的字号层级和减弱动态。
