# Windows 0.46.15 真机测试

2026-10-07 在 Windows 10 Pro 22H2（OS build 19045）测试。测试机起初正式安装 0.46.14；更新使用 `https://ai-daedalus.com/desktop/latest-test.json`，其 Windows 条目为 0.46.15 整包，没有差量 `zip` / `manifest`。正式更新源未操作。新安装包为 10 月 7 日重出的版本，大小 **122,368,071 字节**，SHA-256 为 `f0101c61bd68c93aee734e223ae7e5026f65cdadb655a5c438b23b697370a5b0`，与测试单及下载后的文件一致。

开始前完整备份 `%APPDATA%\DaedalusCRM`。应用内更新使用独立临时数据目录与本地账号服务替身；未使用正式客户资料。安装、卸载测试后，正式数据目录仍在，文件数由卸载前的 2,922 个保持为 2,922 个；安装位置已恢复到原来的 0.46.14。
