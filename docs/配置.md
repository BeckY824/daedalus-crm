# 配置

全部在界面里改，管理员登录 → 左下角账号菜单 → 设置（或 ⌘,）。业务配置那一栏顶上有两个预设：通用销售、教培招生，点一下整组填好。不用改文件、不用重启。

## AI 接入

**推荐 DeepSeek**，设置页选一下填个 Key 就行，地址和模型名都不用管。

为什么只推一家：提示词是照着一家的脾气调的。同一段话在别家模型上的毛病完全不同——
有的不查就敢下结论（库里明明有数据，它答「还没有」），有的爱堆格式（问一个电话先画一张表）。
摆一排选项等于请人去踩没验过的路，而他踩坏了只会认为是这个产品不行。

| | 接口地址 | 模型名示例 |
|---|---|---|
| DeepSeek 官方（推荐） | `https://api.deepseek.com/v1` | `deepseek-chat` |
| 其它 OpenAI 兼容接口 | 它给你的地址 | 它支持的模型名 |

第二行走设置页的「其它（自己填接口地址）」，**能用，但效果我们没逐一验过**——
那是留给知道自己在做什么的人的。中转站、本地推理都归这一行。

「测试连接」会发一次最小请求，回显耗时与模型回复，填错当场知道。

- Key 用会话密钥加密后存库，界面只回显尾 4 位，数据库备份里没有明文
- 也可以用环境变量 `LLM_API_KEY / LLM_BASE_URL / LLM_MODEL`，界面里填的优先
- 同一页显示本月各功能调用次数
- 推理模型的输出预算已按思维链占用留足；不支持 `response_format=json_object` 的网关会自动降级

AI 会把客户姓名与跟进记录发给你配置的接口。用第三方接口前确认其数据政策。

## 业务配置

- **业务简介**：一段话说你们卖什么、客户是谁、怎么成交。进所有 AI 提示词，改这一段，所有 AI 功能一起换语境
- **客户叫什么**：默认「客户」。侧边栏、表头、表单、提示、AI 提示词全站同步
- **三个档案字段名**：默认「公司 / 职位 / 行业」。数据库列不动，只改叫法
- **三组下拉选项**：档案第二格（默认职位）、线索来源、行业
- **状态显示名**：默认已经把几个教培味的值换了说法（已试听→已演示、已决定报名→已决定采购、与家人商议→内部讨论），你还能再改。只改界面叫法，存储值不变——盯盘权重、雷达、首页统计、终态判断都按值引用

不做的：自定义字段、自定义状态流转、多套模板切换。
