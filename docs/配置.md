# 配置

全部在界面里改，管理员登录 → 设置管理。不用改文件、不用重启。

## AI 接入

三个字段：接口地址、API Key、模型名。任何 OpenAI 兼容接口都行：

| | 接口地址 | 模型名示例 |
|---|---|---|
| DeepSeek 官方 | `https://api.deepseek.com/v1` | `deepseek-chat` |
| OpenAI | `https://api.openai.com/v1` | `gpt-4o-mini` |
| 本地 Ollama | `http://host.docker.internal:11434/v1`（本地跑用 `localhost`） | `qwen2.5`，Key 随便填 |
| 各类中转站 | 它给你的地址 | 它支持的模型名 |

「测试连接」会发一次最小请求，回显耗时与模型回复，填错当场知道。

- Key 用会话密钥加密后存库，界面只回显尾 4 位，数据库备份里没有明文
- 也可以用环境变量 `LLM_API_KEY / LLM_BASE_URL / LLM_MODEL`，界面里填的优先
- 同一页显示本月各功能调用次数
- 推理模型的输出预算已按思维链占用留足；不支持 `response_format=json_object` 的网关会自动降级

AI 会把客户姓名与跟进记录发给你配置的接口。用第三方接口前确认其数据政策。

## 业务配置

- **业务简介**：一段话说你们卖什么、客户是谁、怎么成交。进所有 AI 提示词，改这一段，所有 AI 功能一起换语境
- **客户叫什么**：默认「学员」。侧边栏、表头、表单、提示、AI 提示词全站同步
- **三个档案字段名**：默认「院校 / 年级 / 专业」。数据库列不动，只改叫法
- **三组下拉选项**：年级、线索来源、行业
- **状态显示名**：「已试听」可以显示成「已体验」。只改界面叫法，存储值不变——盯盘权重、雷达、首页统计、终态判断都按值引用

不做的：自定义字段、自定义状态流转、多套模板切换。
