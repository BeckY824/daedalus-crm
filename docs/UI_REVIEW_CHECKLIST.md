# UI 体检清单

每隔几个页面跑一次：把页面截下来，逐条过。**能自动查的已经是守卫用例**（色值、动效），
这里是只有人眼能看的部分。一次体检的产物是一张表：页面 × 条目 × 结论（过 / 改了 / 留着），
存到 `docs/shots/体检-<日期>.md`。

## 怎么截

桌面端：`preview_start crm-saas-dev`（3100）或 `npm run dev:shots`（3300，manual.db），
1440×900，每个一级导航页 + 客户记录页 + 设置浮层各一张；有空态的页再截一张空态。

## 逐条

**对齐**
- 同一列的数字右对齐、文字左对齐；图标和文字基线对齐
- 卡片内边距一致；相邻卡片的标题在同一条水平线上

**留白**
- 间距落在 4 的倍数上（`--s1…s6`）；同级元素间距相同
- 一屏里最多两种卡片内边距；没有"这块挤、那块空"

**字号层级**
- 一页只用五级字号；标题 22、区块 15、正文 14、说明 13、下限 12
- 说明文字用 `--text-muted`，**不比它更浅**；placeholder 才用 `--text-faint`
- 同一层级的东西字号字重一致（两张卡的标题不能一个 15 一个 14）

**颜色数量**
- 一屏语义色不超过三种（brand + 一种状态色 + 中性）；分类色只出现在分类的东西上
- 图表主线是 `--brand`；不能有第二个蓝

**状态完整性**（每个列表 / 表单 / 面板都问一遍）
- 空态：说这是什么、第一步做什么，不写"暂无数据"
- 加载：有占位，不闪白
- 错误：说清发生了什么、能做什么，不吞
- 悬停 / 焦点 / 禁用：三种都能看出来；键盘 Tab 能走到每个可点的东西
- 长文本：截断有省略号且 title 里有全文；中文英文数字混排不挤

**动效**
- 只用四档时长；进入用 `--t-enter`，展开用 `--ease-morph`
- 系统开了减弱动态：没有任何位移和缩放（测试钉着，但眼睛再看一遍）

**窗口**
- 1440 和 1200 两个宽度各看一次；1200 时中栏该收就收，正文不出横向滚动条
- 顶部 52px 拖动区里没有可点的东西被遮

**文案**
- 按钮是动词；标题是名词；说明是人话
- 同一个东西全站一个名字（客户 / 学员按业务配置来，不混用）
- 过程条、提示、空态里不出现工具名、字段名、英文缩写

## 记录格式

```
| 页面 | 条目 | 结论 | 备注 |
|---|---|---|---|
| 首页 | 颜色数量 | 改了 | 排行榜前三用了三种色，改成 brand + muted |
```
