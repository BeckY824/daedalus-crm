# Windows 差量更新交接修复（2026-09-29）

基于 `windows-next` 的 `33e10599993a90e9a290fdcf3b48f1b612e8e7b6`。本记录是修复验证，不表示已完成发版验收。

## 问题与复现

用户的旧日志显示，两次 0.46.12 差量组装完成后，都只记录了启动 cmd 的进程号，没有 PowerShell 换目录脚本的 begin 日志。

使用真实 Electron 和临时安装目录复现：原逻辑启动 cmd 后立即退出，连续三次没有换目录；等待 PowerShell 就绪且 cmd 退出后再关闭应用，连续三次成功。C 盘临时目录也能复现，不能归因为用户装在 F 盘。

## 修复

- 更新启动函数改为异步交接：每次创建独立会话，PowerShell 写就绪信号，中转 cmd 成功退出后，主程序才授权更新并允许退出。
- 手动「重启以更新」等待交接；退出时自动应用更新先阻止退出，交接完成再退出，避免重复启动辅助进程。
- 启动错误、非零退出或 20 秒超时会取消本次交接。迟到的脚本不能更换目录；应用仍存活时，辅助程序也不会强行换目录。
- 用短编码引导命令读取本次生成的本地脚本，避免完整脚本和路径撑大 cmd 命令行。
- 移除误提交的 `desktop/node_modules` Mac 私人临时目录软链接；依赖继续由锁文件安装并由已有规则忽略。
- 冒烟测试收尾只结束测试可执行文件路径下的进程，不按名称结束电脑上其它位置的 CRM。
