# Windows 0.46.14 整包更新复测

2026-10-02，在 Windows 上用正式安装的 0.46.13 和测试更新源 `https://ai-daedalus.com/desktop/latest-test.json` 复测 W5、W6。该源的 Windows 条目指向 0.46.14 安装程序，未提供 `zip` 或 `manifest`。下载的安装程序 SHA-256 为 `6c83be18bb568dd70ec8f38a50e2ba2854f69e3fc7efdfffe165cea6cac20444`，与发布说明一致。

| 项目 | 结果 |
| --- | --- |
| W5 | 0.46.13 显示“整包 114 MB”；在隔离数据目录中创建客户与联系人后，从应用内下载、重启安装。0.46.14 自行启动；用新版重新打开同一数据目录后，客户与联系人仍可见。 |
| W6 | 重装 0.46.13 再次走整包更新；旧窗口退出后立即打开应用，出现“正在安装 0.46.14”小窗。安装完成后，0.46.14 主窗口自行出现，未遇到本地服务启动失败。 |

测试使用独立的临时数据目录和本地登录服务替身，未使用真实客户数据；完成后将本机安装位置恢复为 0.46.13。此分支基于官方 0.46.14 标签，不包含另一个本地分支上的差量启动保护修复；Windows 走整包由官网测试更新源控制。
