## 一、B5 日期保存

在同一合成客户分别检查外贸订单和通用签约：

| 场景 | 预期 |
|---|---|
| 编辑已有订单，日期输入 `2026-13-40`，直接点保存 | 弹窗保留、原文保留，明确显示“请输入有效日期（YYYY-MM-DD）”；没有成功提示、数据库旧日期和其他资料不变 |
| 输入非闰日 `2026-02-29` | 同样拒绝，不自动变成 3 月 1 日 |
| 把无效值纠正为合法日期，直接点保存 | 保存纠正后的日期，不沿用先前日期 |
| 新建订单／签约，清空日期再保存 | 必填／无效日期提示，不沿用默认今天，不产生记录 |
| 输入合法日期、日历点选日期，各保存一次 | 详情日期与录入一致；金额、币种、客户和负责人不变 |

只删除本轮额外新建的合成记录。保留日期输入前、拒绝后、纠正保存后截图与记录编号。

## 二、F2 AI 表述

在业务员隔离实例查询 Windows 老板私客 `QA-SAM-F1-Win双向客户`／电话 `13900001611`。先核对该客户确实仍归老板，当前业务员列表、搜索与详情不可见。

- 0 条结果应说明“当前可访问范围内未找到”，无法区分不存在和无权访问。
- 回答及流式过程不能出现“不是权限问题，这个客户在系统里不存在”，也不能反过来确认别人拥有该客户。
- 不返回私有电话、备注或跟进；问题里自己输入的姓名／电话回显不算私有资料读取。
- 再查询一位自己可见的客户，核对正常资料仍能回答；有匹配结果后另一次空查询，不能把已找到的资料抹掉。

## 三、E2/E3 通知点击与账号切换

优先使用当前用户的正式安装目录实例，记下窗口是否最小化、通知在横幅还是操作中心。

1. 停在设置页，点“发一条试试”；实际单击系统通知，须恢复／聚焦应用并进入跟进计划页。
2. 再发一条，等待横幅收起后从操作中心点击，仍须跳转。不能仅凭“已发送”提示记通过。
3. 新建一条合成到点计划，确认只提醒一次；点击后进入对应客户及计划位置，完成／删除后不重复提醒。
4. 账号甲发出通知后切到合成账号乙；甲的旧通知应被关闭，已迟到的点击不能把乙带去甲的资料页。不要改真实账号提醒设置。
5. 如果不跳转，保留本机 `logs/app.log` 中“通知事件”“导航事件”：`shown`、`clicked`、`navigation-sent`、`navigation-acknowledged`／`navigation-fallback`。日志仅记事件编号和类型，不记通知正文或令牌。
